# Procedual生成された東京/お台場都市

## 概要

- BlenderとPythonを使用して東京の建物、道路, 公共交通機関をProcedualに生成するプロジェクトです。
- 生成物はusdなどで出力され, 適切なフォルダ構成でgit管理される
- 道路モデルはOSMの地形データを使用
- UEのMatrixデモくらいフォトリアルにすること。現実と区別がつかないレベルでリアルな都市を生成することを目標とする

## 建物生成

- moduleを複数作ってそれらを組み合わせることで多様な建物の生成を可能にする
- そのためにUSDを使ってモジュールを定義（複数のドア/窓/1span分の壁, 天井、意匠パネル, 柵、非常階段、ドア, 屋上設備など）
- 1つの建物でもフロアごとに階高が異なる(1階だけ天井高が高い、最上階だけ天井高が低いなど)場合があるので、フロアごとにモジュールを定義し,textureも切り替えることで多様なビル種類を生成する
- 天空率や射線制限を考慮して一部の建物は頂点部分がベベルされていたりする
- ベランダがあったり2Fまでと3F以降で意匠デザインが変わったり、途中で建物形状が変わったりetc...
- 窓は引違い/FIX/連窓/縦長スリット/出窓/高窓など形状を複数用意し、ルーバー・フィン(縦/横/斜め/可動/パンチングメタル/格子)や窓まわり意匠(庇・面格子・水切り)も複数用意する
- 1階(基壇部)は上階と別材質・別意匠にする: ガラス張り/御影石・石英系タイル/大理石/レンガ/打放しRC/金属パネル/ピロティ/アーケード等。用途(オフィス・商業・住宅・公共・倉庫)ごとに候補を変える

## 道路生成

- 日本にあるような電灯,標識, 道路標示, 横断歩道, 車止め, ガードレールなども複数のモジュールを個別に生成
- 歩道, 横断歩道、車線や道路標示などもProcedualに生成できるようにすること。なおこれらはtextureで配置し、汚れやカスレも表現できるように
- その他看板、ベンチ、なども実装すること

### 道路のProcedual生成ルール

- 道路ごとに`RoadProfile`(車線数・車線幅・路肩・中央分離帯・歩道ON/OFF(左右別)・歩道幅・歩道/縁石の高さ・植栽帯・自転車レーンON/OFF・路面劣化(wear))を持ち、OSMタグ → 種別デフォルト → 乱数ジッター → ユーザー指定(JSON上書き)の順で決める
- 歩道幅(1.5〜6m)、縁石高(0〜0.2m)、車線数などを自由に設定でき、区間ごとに少しずつ変えてCGっぽさをなくす。切替境界は補間区間でつなぐ。乱数は`(osm_id, 区間index)`でシード固定して再現性を保つ
- 道路が交差する場所は交差点を生成する: 隅切り、横断歩道(スクランブル含む)、停止線、右折レーン、導流帯、歩道コーナーの切り下げ。立体交差(layer違い)は交差点を作らない
- 路面標示は`(s, t)`座標のベクタとして生成し、マスクテクスチャへ焼く: 中央線/車線境界線/外側線/横断歩道/停止線/自転車レーン(青線・矢羽根)など
- 路面記号(矢印・「止まれ」「徐行」等の文字・速度数字・自転車/バスのピクト・ひし形/三角の予告)もProcedualに生成する。日本の路面文字は縦に伸びた形で作る
- バリアフリー: 横断歩道端の切り下げ(勾配8%以下・有効幅1.5m以上)、線状/点状の誘導ブロック(JIS T 9251, 黄)、エスコートゾーンをON/OFF・確率で切替える
- 劣化・ゆらぎ: かすれ(タイヤ通過帯を強く削る)、補修パッチ、ひび、轍、マンホール周りの沈下、油染み、水たまり、標示位置の誤差(±3cm)、旧標示の消し跡
- `city_age` / `wetness` / `barrier_free_rate` / `tactile_rate` / `bike_lane_rate`を設定ファイル1枚に集約し、地区(landuse)ごとの倍率で上書きできるようにする


## NOTE

- moduleを生成する時は非常にフォトリアルにすること. 
- PBRマテリアルを適当ようすること。汚れや傷なども適度に入れる
