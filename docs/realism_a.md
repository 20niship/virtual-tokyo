# リアリズム強化A(照明・建物質感・近景・実写比較)

ブランチ `realism-a`。レンダ側(`render.py` / `render_real.py` / `city_render.py`)と建物の材質に限定した変更で、モジュールの形状は変えていない。

## 使い方

- 小領域+時間帯: `uv run python scripts/build_realism.py <spot> --round N --time day|dusk|night`
  (spot は `scripts/_spots.py` と `spots_extra.SPOTS` の両方)。出力は `out/render/realismA/<spot>[_time]/round<N>/`。
- 一括: `scripts/realism_batch.sh N "shuto:day shuto:night ..."`
- 材質の近接確認: `uv run python scripts/realism_closeup.py out.png <module>... [--time night] [--gn]`
- `city_render.REALISM = False` にすると従来の見た目に戻る。

## 実装

| 項目 | 内容 |
|---|---|
| 空・雲 | 筋雲(方向を平面に投影した異方性ノイズ)。水平線より下は仰角3.5°の空色で埋めて暗い帯を消す |
| 霞 | コンポジタの奥行きパスで `1-exp(-kz)` だけ水平線の色へ混ぜる(世界ボリュームは無限遠の空を消すので不採用)。`HAZE` は水平線の空を実測した値 |
| 露出 | 低解像度・8サンプルの試し撮りの中央値から自動決定(空の飽和画素は除外)。夜だけ光源基準の固定露出 |
| 時間帯 | `day / dusk / night`。夕は太陽仰角4°、夜は月明かり+紫がかった灰色の光害空 |
| 窓ガラス | 透過をやめ「反射+インテリアマッピング」。視線と部屋(3×3×4.5m)の箱の交点で床/天井/側壁/奥壁を塗り分け、窓(3mセル)ごとにカーテン/ブラインド/素通し/点灯をハッシュで決定。夜は点灯セルが電球色/蛍光灯色で発光 |
| 発光 | 夜・夕は街灯・看板・自販機・ヘッドライト・店舗/広告アトラスを発光 |
| 壁の汚れ | `assets/textures/wall_grime.png`(R=雨だれ, G=垂れ染み, B=錆)を Box 投影。インスタンスごとに位置をずらす |
| 目地 | tile/brick/stone/alc に Brick Texture(1枚ごとの色むら、目地色、目地の凹み) |
| 近景 | Bevel ノード(半径1.2cm)、瓦・波板・サイディング・ブロック・石積みはバンプを深く |
| 水面 | 波の法線(2スケール)、深い青緑、粗さ0.05(運河で灯りを映す) |

## 実写との比較(参照のみ・リポジトリには含めない)

| 差分 | 対応 |
|---|---|
| 夜の空は紫がかった灰色(こちらは濃紺) | 光害の色に混ぜた |
| 夜景は点灯率が約3割で窓の色もまばら(こちらは窓が真っ黒) | 窓の発光を窓ごとのハッシュで3〜5割点灯 |
| 筋状の薄い雲、遠景の霞とコントラスト低下 | 筋雲+奥行きフォグ |
| コンクリ橋脚・壁は雨だれで茶〜灰に汚れる(こちらはほぼ白) | wall_grime と強度1.4 |
| 運河の水面は鏡のように建物の灯りを映す | 粗さ0.05 |
| 窓は空を映して暗く、カーテンやブラインドが見える | インテリアマッピング |

## 残課題

- 窓の室内は箱1つ(家具は低い箱の影のみ)。1階店舗の内部は別途。
- 夜の街灯は発光メッシュのみで、路面への光だまりは弱い。
- 霞色は方位平均の固定値で、太陽方向の明るい霞(逆光)は出ない。
- コンクリ橋脚の汚れテクスチャはモジュール共通のため、橋脚だけ別マスクにするとより近づく。
