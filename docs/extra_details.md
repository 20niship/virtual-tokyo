# 追加要素: 田舎・郊外・ロードサイド・工場/コンビナート・高架の細部

東京以外(田舎・中規模都市)にもある建物/土木/屋外設備と、首都高高架の細かい付属物を、部品単位のモジュールと地区タイプ(district)で追加した。
東京の既定動作(`blocks.infill` / 既存の様式)は変更していない。

## 使い方
- 小領域(数百m)の生成とレンダ: `uv run python scripts/build_extra.py <spot> [--round N] [--per 2] [--samples 24] [--only g_|a_|x_]`
  - スポット: `rural / suburb / town / roadside / factory / plant / expwy_west / expwy_bay`(`src/vt/spots_extra.py`)。出力 `out/render/extra/<spot>/round<N>/`。
  - 別の領域でも `city.build_world(half, center_ll=..., mode="infill", district="rural")` で地区タイプを指定できる(`rural/suburb/town/roadside/factory/plant`)。
- 部品のギャラリー: `uv run python scripts/render_extra_gallery.py [group]`(`out/render/extra/gal_*.png`)
- テクスチャ再生成: `uv run python -m vt.textures_extra`(屋根瓦・サイディング・波板・ブロック・汚れコンクリ・店舗看板アトラス)。店名・社名はすべて架空。
- モジュールUSD: `uv run python scripts/write_extra_modules.py`(`assets/modules/*.usdc`)
- 高架の細部は `bridges.elevated_roads` から `expwy.py` が配置するので、どの領域・どのスポットで生成しても入る(`build_city.py` でも同じ)。

## 屋根(`src/vt/roofs.py`)
切妻/寄棟/入母屋/片流れ。屋根材11種(桟瓦2/本瓦/セメント瓦2/立平金属4/スレート2)をメートルUVで貼る。軒の出・ケラバ・鼻隠し・破風・棟(棟瓦)・鬼瓦・軒樋・竪樋・軒天を付ける。

## 建物様式(`src/vt/styles_extra.py`)
`house_jp_kawara / house_jp_mortar / house_kominka / house_maker_a|b|brick / apt_wood2 / barn_tin`、ロードサイド店舗 `rs_<店舗キー>` ×42(+GS事務所)、`factory_tin_gray|blue|green|cream / logistics`。
`Feature.tags["_style"]` で様式を指定すると `build_building` がそれを使う。

## 地区タイプ(`src/vt/district.py`)
- `rural`: 田園集落。住宅は敷地の一部に建て、道路側に板塀/生垣/ブロック塀/石垣+門(薬医門 or 門柱)、カーポート、物置、庭木、(農家)土蔵。空き区画は畑(土/芝+ビニールハウス)。木製電柱を道沿いに。
- `suburb`: 郊外住宅地(メーカー住宅+木造アパート+RC低層)。
- `town`: 中規模都市の幹線沿い(住宅/アパート/雑居/店舗の混在)。
- `roadside`: 区画を道路側(駐車場+ポール看板+のぼり)と奥(店舗)に分割。GSは専用レイアウト。
- `factory`: 町工場(波板+煙突)/物流センター(ドック+トレーラー)+ヤード+フェンス。
- `plant`: コンビナート。タンクヤード(防液堤+配管)またはプロセスエリア(配管ラック+塔槽+煙突/フレア+冷却塔+計器室)。

## 高架の細部(`src/vt/expwy.py`)
- 橋脚: 縦樋(桁側の横引き管から降りる)、点検ハシゴ、足場金具、番号板、非常電話(根元)、鳥よけネット、落橋防止、桁下照明。柱は汚れたコンクリート(雨だれ・カビ)にし、柱脚2.4mは落書き防止塗装。
- 桁沿い: 照明柱(30m)、非常電話(250m)、CCTV、案内標識/情報板(500m)、ケーブルトレイ(6m)、伸縮装置下カバー(90m)、陸上の桁下4.5〜15mに非常階段。

## 残課題
- 瓦などの屋根は法線ベースの簡易UV。入母屋の下屋/上屋の取り合いは単純化。
- 店舗ファサードは1階平屋中心。パチンコ・スーパーの2階以上の外壁は簡易。
- コンビナートの配管は区画内の配置のみ(区画間をつなぐパイプラインは未実装)。
- 非常階段は桁へ渡る通路を省略(踊り場の端が桁縁に近づく配置のみ)。
