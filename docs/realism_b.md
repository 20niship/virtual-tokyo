# リアリズム強化B(車両・人・路面・街の生活感・スケール検証)

ブランチ `realism-b`。担当範囲: 車と人の質感、路面/歩道の経年ディテール、街の生活感の小物、実寸の検証。

## 実行

- 確認レンダ: `uv run python scripts/realismB_views.py <spot> <round> [--only vend,ac,peds,cars,low,...]` → `out/render/realismB/<spot>/round<N>/`
  (spot: `odaiba_intersection` `west_intersection` `west_highrise` `yurikamome` `shuto`)
- スポット全体: `RENDER_ROOT=realismB uv run python scripts/build_city.py --spot west_intersection --render --per 3 --round 1`(`--no-life` で今回の追加を無効化して比較できる)
- 部品ギャラリー: `ROUND=r1 uv run python scripts/render_realismB_gallery.py cars big two ped_a ped_b ped_c life_a life_b life_c life_d`
- テクスチャ再生成: `uv run python -m vt.textures_b`(git管理、約3MB)。モジュールUSD: `uv run python scripts/write_realismB_modules.py`

## 実寸の照合結果

- 車: 全長/幅/高さが国内の代表車種の範囲内(セダン4.2〜5.0m、軽3.2〜3.7m×1.45〜1.8m、バス10〜12m)。アーチ円盤が地面より0.09m下に出ていた不具合を修正。
- 人: 成人1.5〜1.95m、子供0.95〜1.5m。自転車 全長1.6〜1.9m・高さ0.95〜1.2m。
- 道路: `roads.BASE` の車線幅2.4〜3.6m、歩道1.5〜6.0m(既存の値は妥当)。
- 建物: 階高が一律3.5〜3.6mだったため、住宅(3.0m)が高く事務所が低く出ていた → 用途別に変更。
- 柱/小物: 電柱12m、カラーコーン0.7m、ボラード0.84m、標識0.6m角は妥当。

## 参照した資料(実寸)

- 自動販売機: 自治体の設置仕様書(岡山市・埼玉県・阿見町 等)の設置寸法 → 幅1.2m前後×奥行0.7〜0.95m×高さ1.9〜2.0m以内。自販機モジュールを幅1.16m×奥行0.8m×高さ1.94mに合わせた。
- くさび式足場: 建枠幅1.8m(6尺)・階高約1.9m・手すり高さ0.9m。足場モジュール(幅1.8m、階高1.9m、手すり0.45/0.9m)の根拠。
- ナンバープレート: 330×165mm(2:1)。

## レンダ確認(各ラウンドで直した点)

画像は `out/render/realismB/<spot>/round<N>/`(gitignore、`sheet_*.jpg` が一覧)と `out/render/realismB/final/gal_*.png`(部品ギャラリー)。

1. ラウンド1(west_intersection、部品ギャラリー): 車の白い塗装が汚れノイズで迷彩のようにまだらになった → 色ごとの画像(下端の泥跳ね+雨だれ)に変更。人の髪が顔の前面を覆っていた → 頭頂と後頭部のみに。スクーターのレッグシールド/ダンプの荷台/養生ネットの押し出し軸の取り違えを修正。のぼり・自販機の文字の左右反転を直した。
2. ラウンド2(odaiba_intersection、west_highrise): 人が棒状で細かった → 手足を太く、胴を楕円(16角)、目・鼻・ベルトを追加。髪色が金髪に偏っていた → 黒髪を大半に。足場が4000インスタンスで過多 → 約10万m²あたり1棟・最大6段に抑えた。路面オーバーレイを増量、歩道の落ち葉と柱上変圧器/通信接続箱/ガス・給湯器の壁付き設備を追加。
3. ラウンド3(west_intersection、shuto、west_highrise): 低い視点で車線上のバン/軽/ワゴン・スクーター・自転車、歩道の植込み・自販機・室外機・駐輪・のぼり・電柱付属物が自然に並ぶことを確認。視点がカメラ位置の車に重なる問題はビュー選定側(6m以内の除外)で回避。

配置数の例(west_intersection、半径200m): 路面オーバーレイ 落ち葉41・水たまり6・油染み11・タイヤ痕10・復旧帯4・マンホール36・縁石欠け17・雑草50、props 計約2,600。

## 残課題

- 人は低ポリのマネキン調(顔は目と鼻のみ)。近接(3m以内)では不自然。
- 車は面ごとのフラットシェーディングのため、丸みのある面が角張って見える(レンダ側のスムースシェード対応が必要)。
- 歩道の建物際に細い黒い隙間が見える箇所がある(今回の追加以前から。原因は未特定)。
- 足場・仮囲いは建物の外周辺ごとに配置するだけで、建物の角の処理や出入口は簡易。
