# Terra 道路・橋・トンネル(T4)

レシピ例(`recipes/terra/virtual_2km_road.yaml`):

```yaml
places: {village_a: [0.608, 0.463], village_b: [0.915, 0.903]}      # 集落(格子比 x, y)
steps:
  - ...                                                              # 地形・侵食・hydro.rivers まで
  - infra.road: {connect: [village_a, village_b], max_grade: 0.10, allow_tunnel: true, allow_bridge: true, bridge_cost: 16, tunnel_cost: 40}
  - infra.village: {}                                                # 集落(家屋・畑・取り付け道。敷地を整地)。スキャッタの exclude に village_pads を足す
  - masks.slope: {}                                                  # 高さが変わったので再計算(再接地)
  - hydro.flow: {}
  - biome.jp_forest: {}
  - ...scatter.*                                                     # 道路・橋・坑口の伐採帯を避けて散布
  - infra.furniture: {}                                              # ガードレール・擁壁・落石防止網・カーブミラー・側溝・縁石・橋桁・橋脚・坑口・トンネル内部
```

既定値と出典の扱いは `docs/terra/infra_defaults.md`(原文で確認できた数値は無く、すべて設計上の既定値)。

## 処理の流れ
1. **経路(`infra/route.py`)**: 粗い格子(4 セル = 8m)で A*(Numba)。1 手 = 16 方向の基本ベクトル。通常の手は「縦断勾配 <= 上限(0.94 倍)」のものだけ許すので、急斜面では等高線に沿った折り返し(つづら折り)になる。費用は距離 x(1 + 傾斜² + 勾配² - 既存路線の割引)+ 標高差。川の上と湖は通常の手では通れない。
   さらに長い手(弦)を許す: **橋** = 弦の下に地面があり(隙間 >= 4m。川を跨ぐなら不問)、地面が弦を 1m 以上突き抜けない、隙間 <= 45m / **トンネル** = 坑口から 25m 以遠で土被り >= 10m、水の下を通らない。どちらも弦の勾配 <= 上限。費用は 橋 16/m + 0.12 x 高さ、トンネル 40/m(通常路と比較され、安い方が選ばれる)。
2. **中心線と縦断線形(`infra/road.py`)**: 通常区間を Chaikin で平滑化し、最小曲線半径(`min_radius` 既定 15m)を満たすよう曲率を広げ(`limit_curvature`)、橋・トンネルは直線のまま 2m 間隔に再標本化。路面高は探索の頂点高を弧長で補間(頂点間の勾配は探索で上限以内)→ 軽く平滑化 → 点間隔ごとの勾配上限で押さえる。
3. **切土・盛土(`infra/earthwork.py`)**: 中心線から最寄りの点の高さを路盤(幅 6.5m の水平面)とし、外側を法面で地形へすり付ける(切土 = 路面+距離/比 と地形の min、盛土 = 路面-距離/比 と地形の max なので縁で連続)。地形の傾斜が 30 度超/42 度超なら法面を 1/2・1/4 に立てる(擁壁・岩盤切土)。橋の区間は触らず、川の上は変えない。トンネルは坑口の手前 16m に急な切り通し。
4. **橋(`infra/bridge.py`)**: 径間は最大 32m。橋脚は桁の下面から地面まで(高さ 4〜45m の module から上側を選び根元を地中へ)。路面が地面から 2.5m 未満で 40m 未満は沈下橋(欄干なし)。
5. **付属物(`infra/furniture.py`)**: 盛土側(5.5m 先の地面が 1.5m 以上低い)にガードレール、切土 3m 以上に擁壁、6m 以上に落石防止網、半径 35m 未満のカーブの外側にカーブミラー、橋に桁(8m ごと)と橋脚、トンネルの両端に坑口。
6. **出力**: 層 `height`(切土盛土後)・`road`(路盤マスク)・`cutfill`[m]、ベクタ `roads`(通常区間と橋。`z` 路面高・`clear_width` 伐採帯)・`tunnels`・`portals`・`road_stats`(統計)、散布グループ `road_furniture`。散布(木・低木・岩・地面)は `road`(伐採帯 22m)と `portal` を除外。USD は路面の曲面メッシュ(`/Terra/Roads`、アスファルト+白線)と PointInstancer。

## 検証レンダで見つけた違和感と対応
| # | 違和感 | 対応 |
|---|---|---|
| 1 | 探索の経路と標高がずれ、橋・トンネルの種類が入れ替わる/土被り 100m の「橋」になる | 経路復元の手の種類の添字ずれと、弦の標高サンプルの縮尺(粗い→細かい格子)を修正 |
| 2 | 縦断勾配が 0.3 を超える | 路面高を探索の頂点高から作り(勾配が上限以内)、点間隔ごとの許容差で押さえた。端点の弦は 0.94 倍の余裕 |
| 3 | 切土が 200 万 m³ になる(急斜面で法面が地形に届かない) | 地形の傾斜に応じて法面を立てる(擁壁・岩盤切土)。切土 2.5 万 m³ に |
| 4 | 山腹がほぼ全て橋・トンネルになる | 橋の条件を「隙間 4m 以上(川を跨ぐなら不問)」にし、橋 16/m・トンネル 40/m に |
| 5 | カメラが切土法面の中に埋まる | 路面の高さから撮る(`road_poses`) |
| 6 | 近接で路盤に微細起伏が乗る | near の微細起伏を路盤から 1m 離れるまで消す |
| 7 | 切土の法尻が 2m 格子の階段状/擁壁の端がギザギザ | 法面の min/max の折れをガウスで丸める(路盤から離れるほど強く)。擁壁・ガードレール・側溝の区間は平滑化・隙間埋め・短い断片除去 |
| 8 | トンネル内部が未作成 | 坑口を切り通し(16m)の奥端へ移し、坑口の間を `tunnel_inner_8m`(馬蹄形の覆工・路面・外側線と破線・歩道・照明)で埋める。far は路面と暗い天井だけの簡易版 |
| 9 | 俯瞰で道路が細く暗くて見えにくい | 路面を明るい使い込みアスファルト(平均 約 100/255。旧 61)、路肩 0.8m の砂利帯を足し、遠景 LOD(`--road-widen`、far 既定 1.7 倍)で幅を太らせる |
| 10 | 集落・側溝・縁石が無い | `infra.village`(家屋 3 種+納屋・畑 2 種・取り付け道、敷地を整地)、`road_ditch_u_4m` / `road_ditch_cover_4m` / `road_curb_4m` |
| 残 | 構造物(橋・トンネル)との継ぎ目の折れ(橋どうし・橋とトンネルで方向が変わる所)は半径 15m 未満になりうる | 全体を平滑化すると構造物が最大 44m ずれたため見送り |
