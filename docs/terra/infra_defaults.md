# Terra 道路・橋・トンネルの既定値と出典

道路構造令(政令)・「道路構造令の解説と運用」の原文で確認できた数値は無い。国土交通省の資料(下記)は検索で存在を確認したが、縦断勾配・幅員の数値までは読み取れなかったため、
**下表の値はすべて「設計上の既定値」**(山間部の道路としてよく言われる範囲に置いた仮の値)である。規格に合わせる場合は原文で確認して置き換えること(すべてレシピのパラメータまたは定数で変更できる)。

確認に使った資料(数値の根拠としては使っていない):
- 国土交通省「道路構造令」関連資料: https://www.mlit.go.jp/road/sign/pdf/kouzourei_3-1.pdf (種別・級別の区分、設計速度の表)
- 国土交通省 道路統計 https://www.mlit.go.jp/road/toukei_chousa/road_db/pdf/2023/13-1.pdf

| 項目 | 既定値 | パラメータ | メモ |
|---|---|---|---|
| 縦断勾配の上限 | 10%(0.10) | `infra.road.max_grade` | 設計上の既定値。8〜12% の範囲で設定可。探索では 0.94 倍の余裕を持たせ、縦断線形の押さえで必ず守る |
| 路盤の幅 | 6.5m(車道 5.5m + 路肩 0.5m x 2) | `width` | 設計上の既定値 |
| 切土法面 | 水平:鉛直 = 0.8 : 1(傾斜 30 度以下の地形)/ 0.4 : 1(42 度以下)/ 0.2 : 1(それ以上=岩盤・擁壁) | `cut_ratio`、`earthwork.STEEP` | 設計上の既定値 |
| 盛土法面 | 1.5 : 1(急斜面は 0.75 / 0.375 : 1 = 擁壁で立てる) | `fill_ratio` | 設計上の既定値 |
| 法面の影響範囲 | 70m | `earthwork.REACH` | これより遠くは地形を変えない |
| 伐採帯(散布の除外) | 道路の中心から 11m(幅 22m) | `clear_width` | 設計上の既定値 |
| 橋: 谷を跨ぐ条件 | 弦の下の隙間 >= 4m(川を跨ぐなら隙間不問)、隙間 <= 45m | `route.find_route`(`max_clear`) | 設計上の既定値 |
| 橋の径間 | 最大 32m。橋脚は桁の下面から地面まで(高さ 4〜45m の module から選ぶ) | `bridge.SPAN_MAX` | 設計上の既定値 |
| 沈下橋 | 路面が地面から 2.5m 未満かつ長さ 40m 未満 | `bridge.CHINKA_CLEAR` | 設計上の既定値 |
| トンネル: 土被り | 坑口から 25m 以遠で 10m 以上 | `min_cover` | 設計上の既定値 |
| 費用の単価(探索) | 通常 約 1〜7/m(傾斜・勾配で増える)、橋 16/m + 0.12 x 高さ、トンネル 40/m | `bridge_cost`、`tunnel_cost` | 相対値。大きいほど橋・トンネルを避ける |
| 坑口の切り通し | 坑口の手前 16m、法面 0.3 : 1 | `earthwork.PORTAL_LEN` | 設計上の既定値 |
| カーブミラー | 半径 35m 未満の急カーブの外側 | `mirror_radius` | 設計上の既定値 |
| ガードレール | 盛土側で、路面から 5.5m 先の地面が 1.5m 以上低い所 | `guard_drop` | 設計上の既定値 |
| 擁壁 / 落石防止網 | 切土の高さ(5m 先の地面 - 路面)が 3m 以上 / 6m 以上 | `wall_cut`、`net_cut` | 設計上の既定値 |
| 最小曲線半径 | 15m(通常区間。橋・トンネルの弦は直線) | `infra.road.min_radius` | 設計上の既定値(原文未確認)。曲率 κ=dθ/ds をガウスで広げて(旋回角は保存)最大 |κ| <= 1/R にし、始点から積分し直して終点を合わせる(緩和曲線の代用)。構造物との継ぎ目の折れは対象外 |
| 路肩 | 0.8m(舗装の外側の水平帯。舗装は幅 6.5m) | `infra.road.shoulder` | 設計上の既定値。側溝・縁石・ガードレールはこの帯に載る |
| 側溝 | 切土側に内幅 0.3m・深さ 0.3m の U 字溝(集落の半径内は蓋付き) | 切土の高さ(5m 先の地面 - 路面)> 0.5m の区間 | 設計上の既定値 |
| 縁石 | 緩い盛土側(落差 0.4m〜`guard_drop`)に高さ 0.15m | — | 設計上の既定値 |
| 集落 | 家屋の中心は道路中心から 11.5〜19m、家屋どうし 19m 以上、傾斜 13 度以下、整地の切盛り 2.2m 以下、道路から 9m 以上 | `infra.village` のパラメータ | 設計上の既定値 |
| トンネル断面 | 幅 7.5m・頂点高 5.0m の馬蹄形、覆工厚 0.5m、歩道 0.5m、照明は 8m ごとの帯状灯 | `lib_road._tunnel_inner` | 設計上の既定値 |
