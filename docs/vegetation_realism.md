# 樹木のリアル化

ブランチ `worktree-agent-a055123ff65269e4c`(dev から)。対象: `tree_gen.py` `lib_veg.py` `vegetation.py` `veg_textures.py` と、葉/樹皮の材質(`materials.py` `render.py`)。

## 1. 現状確認(変更前)

`scripts/veg_compare.py t0 street|park` で同一カメラの近景/見上げ/遠景を撮影(`out/render/veg/t0_*`、gitignore)。

- 葉が大きなカード状: 葉クラスターカードが 1 枚 2〜3.5m(`leaf_size*H*1.7〜2.6`)。近景では葉1枚が人の顔ほどに見え、遠景では板の貼り合わせ(輪郭がギザギザの塊)になる。
- 幹と枝が単純: 枝は 3 レベルだが本数が少なく、葉カードに隠れる。根張りが弱く、樹皮は色テクスチャの輝度バンプのみ(粗さ一定)。
- 樹形が種ごとに似る(どれも丸い塊)。

## 2. 変更内容

| 項目 | 内容 |
|---|---|
| 樹形 | ケヤキ=ほうき状(枝が上向き扇状、冠幅0.46)、イチョウ=円錐(冠幅0.3、枝が短く上向き)、クスノキ=太い幹(girth1.55)+丸い大冠(幅0.7)、サクラ=低く水平に張り出す傘状(冠幅0.78、枝先が垂れる)。クロマツ/ヤシ/ヤナギは従来のまま |
| 分岐 | `spawn()` による再帰(主枝→側枝→小枝)。子枝は親の途中から出て、太さ・長さ・角度を親から継承。枝の太さは先端へ `(1-t)^0.8` で先細り。幹の太さに揺らぎ、根元から板根(5〜7本)、幹は10角形 |
| 葉 | クラスターカードを 0.3〜0.7m(実寸比)にし、樹冠表面積に比例して枚数を増やす(最大2300)。内部にも葉を置いて中空に見えないように |
| 葉シェーダ | オブジェクト座標ノイズで葉塊ごとの色むら、裏面は透過光(Translucent)を強める、個体ごとの色相(bvar)は従来どおり。季節色はアトラスの季節カード(春/夏/黄葉/紅葉) |
| 樹皮 | `bark_*_h.png`(高さ画像)から Bump(ノーマル)と粗さ(凹部ほど粗い)を作る |
| 落ち葉 | `veg_litter_{y,r,b,g}`(3m角のデカール・葉スプライトを黄/赤/枯葉/青葉に染色)を樹下にインスタンス配置。1本あたり 秋4・冬3(枯葉)・春1・夏0.5(青葉)。道路上には置かない。道路縁の落ち葉は既存の `overlays.py` |
| インスタンス | 植栽は従来どおり PointInstancer(USD)/ GN(レンダ)。落ち葉もモジュール1つを複数配置 |
